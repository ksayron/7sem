# КИС. Лабораторная работа № 4

**Тема:** программирование на встроенном языке «1С:Предприятие 8».

**Цель:** разработать процедуры с параметрами, использовать условия, математические функции, даты и циклы.

## Что подготовлено

- `infobase/1Cv8.1CD` — отдельная файловая информационная база.
- `src/ManagedApplicationModule.bsl` — читаемый исходник модуля.
- `configuration/` — выгрузка конфигурации в XML и BSL для переноса или восстановления.
- `screenshots/` — фактические результаты запуска в 1С.
- `verification.md` — результаты проверки и контрольные суммы предыдущих баз.

Платформа: **1С:Предприятие 8.3.27.1508, учебная версия**, Windows. Конфигурация использует управляемое приложение, русский язык, без справочников и документов. Базы `CIS/lab1` и `CIS/lab2` не используются.

## Как запустить

Из PowerShell, находясь в папке лабораторной:

```powershell
& 'D:\Soft\1C\8.3.27.1508\bin\1cv8t.exe' ENTERPRISE /F "$PWD\infobase"
```

Либо добавьте существующую базу в стартовом окне 1С: **Добавить → Добавление в список существующей информационной базы → На данном компьютере**, каталог `D:\BSTU\7sem\CIS\lab4\infobase`. Название можно указать «КИС — Лабораторная № 4». Затем нажмите **1С:Предприятие**.

Ожидаемые сообщения при каждом обычном запуске:

```text
Пользователь! Добро пожаловать!
8
Рабочих дней: 5. Выходных дней: 2
```

Их выводит обработчик `ПриНачалеРаботыСистемы()`. Пустая рабочая область нормальна: лабораторная демонстрирует вывод через `Сообщить()`, отдельных форм нет.

Дополнительные граничные примеры:

```powershell
& 'D:\Soft\1C\8.3.27.1508\bin\1cv8t.exe' ENTERPRISE /F "$PWD\infobase" /C 'Проверка'
```

Обычный запуск следует предварительно закрыть. Параметр `/C` доступен в коде как `ПараметрЗапуска`; в этом режиме после основных сообщений выводятся подписанные проверки.

## Как открыть и изменить код

```powershell
& 'D:\Soft\1C\8.3.27.1508\bin\1cv8t.exe' DESIGNER /F "$PWD\infobase"
```

1. Нажмите **Конфигурация → Открыть конфигурацию**.
2. Нажмите правой кнопкой на корне дерева **ЛабораторнаяРабота4 → Открыть модуль приложения**. В этой конфигурации основной режим — управляемое приложение, поэтому открывается соответствующий модуль.
3. В начале модуля находятся три демонстрационных вызова. Здесь можно изменить имя, приветствие, числа и интервал дат.
4. Выполните **Текст → Проверка модуля** (также кнопка «Проверка модуля» на панели редактора), сохраните конфигурацию и обновите конфигурацию базы данных (**F7**).
5. Запустите приложение (**F5**). Если 1С предлагает обновить конфигурацию базы — подтвердите обновление.

Исходник в `src/` сам по себе не меняет базу. При изменении сохраните одинаковый текст в модуле конфигуратора, `src/ManagedApplicationModule.bsl` и `configuration/Ext/ManagedApplicationModule.bsl`.

## Выполнение заданий

### 1. Приветствие

`ПоприветствоватьПользователя(Приветствие, Пользователь)` соединяет имя, восклицательный знак и приветствие, затем передаёт строку в `Сообщить()`.

### 2. Работа с числами

`РезультатВозведенияВСтепеньДоГраницы(Число, Степень, Граница)` вычисляет степень через `Pow(Число, Степень)` и проверяет `Результат < Граница`.

При `2, 3, 10` выводится `8`. При `2, 3, 8` и `2, 4, 10` выводится предупреждение с соответствующей границей. Текст предупреждения сохранён точно по заданию, поэтому он используется и при равенстве, хотя слово «превышает» в этом случае математически неточно.

### 3. Подсчёт числа дней

`ПодсчетЧислаДней(ДатаНачало, ДатаКонец)`:

1. Приводит обе даты к началу дня с помощью `НачалоДня()` в локальных переменных.
2. Проверяет порядок дат. При обратном интервале выводит ошибку и завершает процедуру через `Возврат`.
3. Обнуляет счётчики `РабочиеДни` и `ВыходныеДни`.
4. Обходит даты циклом `Пока` с условием `<=`, включая оба конца интервала.
5. При `ДеньНедели() <= 5` увеличивает число рабочих дней, иначе — выходных.
6. Переходит к следующему дню прибавлением `86400` секунд и выводит итог.

02.11.2026 — понедельник, 08.11.2026 — воскресенье. Получается 5 рабочих и 2 выходных дня. Учитывается только день недели: государственные праздники и переносы рабочих дней не входят в алгоритм задания. Например, 07.11 здесь классифицируется как суббота.

## Ответы на контрольные вопросы

### 1. Как создать процедуру / функцию?

Процедура выполняет действия; функция возвращает значение через `Возврат`:

```bsl
Процедура ПоказатьСумму(А, Б)
    Сообщить(А + Б);
КонецПроцедуры

Функция Сумма(А, Б)
    Возврат А + Б;
КонецФункции
```

### 2. Как вызвать процедуру?

Указать её имя и аргументы: `ПоказатьСумму(2, 3);`. Результат функции можно присвоить переменной: `Итог = Сумма(2, 3);`.

### 3. Какие есть типы данных?

Основные: `Число`, `Строка`, `Дата`, `Булево`, `Неопределено`, `Null`, `Тип`. Коллекции: `Массив`, `Структура`, `Соответствие`, `ТаблицаЗначений` и другие. Прикладные типы связаны с метаданными: например, `СправочникСсылка.Номенклатура`, если такой справочник существует в конфигурации. `Неопределено` и `Null` — разные значения; `Null` встречается, в частности, в результатах запросов.

### 4. Как создать переменную?

Явно: `Перем Сумма, Количество;`, затем отдельно `Сумма = 0;`. Неявно — первым присваиванием: `Имя = "Иван";`. Тип определяется текущим значением. В BSL объявление `Перем Результат = 0;` из теоретического примера некорректно: объявление и присваивание записывают отдельно.

### 5. Как оформить условие?

```bsl
Если Сумма < 10 Тогда
    Сообщить("Меньше десяти");
ИначеЕсли Сумма = 10 Тогда
    Сообщить("Равно десяти");
Иначе
    Сообщить("Больше десяти");
КонецЕсли;
```

### 6. Как создать цикл?

`Для Счетчик = 1 По 10 Цикл ... КонецЦикла;` — известное количество повторений. `Для Каждого Элемент Из Коллекция Цикл ... КонецЦикла;` — обход коллекции. `Пока Условие Цикл ... КонецЦикла;` — повторение, пока истинно условие. Для дат в лабораторной используется `Пока`.

### 7. Что такое событийно ориентированная модель?

Платформа вызывает обработчики в ответ на события: запуск приложения, нажатие кнопки, запись объекта, закрытие формы. Разработчик описывает действия в соответствующих процедурах-обработчиках; постоянный ручной вызов этих процедур не нужен.

### 8. Какое событие возникает при запуске приложения?

Для выполненной лабораторной используется `ПриНачалеРаботыСистемы()` в модуле управляемого приложения. Платформа вызывает его при начале работы приложения. Также существует более ранний обработчик `ПередНачаломРаботыСистемы(Отказ)`.

### 9. Что такое универсальные коллекции?

Это объекты для хранения и обработки наборов значений, не привязанные к конкретному справочнику или документу: массивы, структуры, соответствия, списки значений, таблицы и деревья значений. Они различаются организацией и способом доступа к элементам.

### 10. Как работать со Структурой / Массивом / Соответствием?

```bsl
// Массив: индекс начинается с нуля, порядок элементов сохраняется.
Имена = Новый Массив;
Имена.Добавить("Анна");
ПервоеИмя = Имена[0];

// Структура: строковые ключи — допустимые имена свойств.
Данные = Новый Структура;
Данные.Вставить("Имя", "Анна");
Имя = Данные.Имя;
Если Данные.Свойство("Имя", НайденноеИмя) Тогда
    Сообщить(НайденноеИмя);
КонецЕсли;

// Соответствие: ключами могут быть значения разных типов.
Оценки = Новый Соответствие;
Оценки.Вставить("Анна", 10);
Оценка = Оценки.Получить("Анна");
```

У коллекций есть методы для добавления, удаления и получения элементов. Их можно обходить циклом `Для Каждого`.

### 11. Для чего нужен синтаксис-помощник?

Для поиска описаний языка, типов, методов, свойств, событий и параметров, включая доступность в клиентском или серверном контексте. Открывается через меню **Справка → Синтакс-помощник** или **Ctrl+Shift+F1**. Для задания 2 нужен раздел глобального контекста с числовыми функциями, в частности `Pow()`.
