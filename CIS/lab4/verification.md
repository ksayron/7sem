# Проверка лабораторной № 4

Проверено 11.11.2026 на установленной учебной платформе **1С:Предприятие 8.3.27.1508**. Выполнение проверялось в самой 1С, без эмуляции BSL другим языком.

## Конфигурация

- Создана новая файловая база `infobase/1Cv8.1CD`.
- Модуль загружен через пакетный режим конфигуратора `/LoadConfigFromFiles`, конфигурация базы обновлена через `/UpdateDBCfg`. Результат: «Обновление конфигурации успешно завершено».
- Проверка `/CheckConfig -ThinClient -ThickClientManagedApplication -Server`: **«Ошибок не обнаружено»**. Вывод сохранён в `configuration-check.txt`.
- Обратная выгрузка `/DumpConfigToFiles` подтверждает наличие `Ext/ManagedApplicationModule.bsl` в базе и совпадение с исходником `src/ManagedApplicationModule.bsl` после нормализации переводов строк.
