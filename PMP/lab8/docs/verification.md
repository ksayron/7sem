# Проверка лабораторной №8

## Вход и выход — 10 ноября 2026 года

Добавлены отдельная форма входа и экран `Profile`. Вместо выбора роли в каталоге используются локальные демоаккаунты с паролями (см. README). Поддерживаются проверка обязательных полей, показ пароля, автозаполнение, отправка с клавиатуры, состояние выполнения, ошибки входа, отмена и подтверждение выхода. Смена сессии пересоздаёт навигацию: назад в предыдущую сессию вернуться нельзя. Сохраняются вход, выход и персональное избранное; прежний выбор пользователя при обновлении требует нового входа без удаления данных.

Новые экраны продолжают существующий дизайн: тёмные поверхности, кофейный акцент, Material-контролы и прокручиваемые формы. Новая визуальная концепция не вводилась.

## Android

Команда:

```powershell
flutter drive --driver=test_driver/integration_test.dart --target=integration_test/lab8_test.dart -d emulator-5554
```

Сценарий **All tests passed**: [android-test.log](android-test.log), структурированные результаты [android-results.json](android-results.json).

Через интерфейс проверены выбор роли, создание товара с ценой 5.25, расположением Minsk, рейтингом 4.8 и 42 отзывами, поиск, отображение полей, изменение цены на 6.75 и описания, добавление в избранное Emma, пустое избранное Daniel, удаление с подтверждением. Дополнительно на устройстве вызваны три запрещённые операции репозитория под обычным пользователем: получен отказ.

После закрытия и повторного открытия репозитория на Android сохранились активный пользователь, изменённые поля и избранное. После удаления всех товаров и повторного открытия каталог остался пустым. Интеграционный сценарий использует отдельный временный каталог и удаляет собственные данные; обычная пользовательская база не очищается.

Отдельно установлен и запущен обычный APK из `lib/main.dart`. Через Android UI выбран Daniel и добавлен Espresso в избранное, затем процесс остановлен командой `adb shell am force-stop by.bstu.coffee_lab8` и заново запущен через `am start`. После полной остановки процесса сохранились **Daniel** и **Espresso** в его избранном. Временные лайки убраны, выбран исходный пользователь Emma. Результат: [native-restart.json](native-restart.json); [снимок избранного после перезапуска](screenshots/native-favorites-restarted.png). Для этой проверки использовались ADB и дерево доступности Android, без ручного ввода на физическом устройстве.

Реальная попытка чтения демонстрационного бокса вторым ключом вернула `HiveError: Wrong checksum in hive file. Box may be corrupted.`. Исходным ключом прочитана строка `Coffee Lab 8: encrypted control record`. Рабочие товары и лайки после опыта сохранились.

Демонстрационное уплотнение: **84 080 → 753 байта**, одна актуальная запись сохранена. Проверено уплотнение каждого из четырёх рабочих боксов с выводом размеров и количества записей.

## Совместимость сборки

Для установленного SDK закреплён `path_provider_android: 2.2.23`; версия 2.3.1 подключала JNI с требованием Android SDK 35, которого здесь нет. В проекте согласованы AGP 9.1.0 и Kotlin 2.4.0 для приложения и Android-плагинов Flutter. Глобальные файлы Flutter, пакетов и предыдущих лабораторных не исправлялись.

В сборке остаются предупреждения инструментов об ограниченном Java native access, устаревших Gradle API и атрибуте package в манифестах плагинов; они не препятствовали проверенной сборке и запуску. Release-сборка, публикация и подпись для магазина не выполнялись.
