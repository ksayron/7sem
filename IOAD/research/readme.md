# Эксперименты с DotaScience

06.10.2026 дальнейший подбор остановлен по решению пользователя: для лабораторных выбирается другой датасет. Работающие версии лабораторных 4–7 пока остаются на DotaScience; новый набор ещё не утверждён.

Здесь сохранены аудит данных и результаты поиска на полном наборе из 47 150 матчей. `pilot_validation.csv` и `tune_validation.csv` содержат измеренные результаты на валидационной части. Условия разбиения записаны в `protocol.json`, списки матчей — в `split_manifest.csv`.

Проведены аудит, первичное сравнение и этап `search_models.py --stage tune`. Остальные скрипты подготовлены для последующих этапов, но **не выполнены**: поиск kNN, адаптивный подбор, обязательная сетка SVC, проверка финалистов и финальный тест. Поэтому в этой папке нет подтверждённых итоговых метрик на 9472 отложенных матчах и зафиксированных выбранных моделей.

Предыдущие результаты на 6000 матчах сохранены в `../archive/dotascience_6000/`. Исходный CSV не изменён. Эксперименты не заменяли код лабораторных.
