# DotaScience

Общий исходный файл для лабораторных 4–7: `tb_pro_players_matches.csv`.

- [Страница датасета](https://www.kaggle.com/datasets/teocalvo/dota2-pro-players-matches-2019-202106).
- [Код автора](https://github.com/TeoCalvo/DotaScience).
- Лицензия: CC BY 4.0, автор Téo Calvo.
- Скачано 05.10.2026 через публичный API Kaggle. Размер CSV: 189 615 121 байт.
- SHA256: `5844598356D0D8A156260457E3F961008410519083CC3E0B020FB230E9534D07`.

В таблице 47 150 строк и 317 столбцов: идентификатор `match_id`, дата `dt_match`, ответ `radiant_win` и 314 числовых показателей. Цель уже бинарная: False — победа Dire, True — Radiant. В полном CSV 22 599 побед Dire и 24 551 победа Radiant; повторяющихся match_id нет.

По описанию автора признаки рассчитаны на день до матча по предыдущим шести месяцам игры участников. Это историческая статистика участников, а не результаты текущего матча. Суффиксы `_r` и `_d` обозначают команды Radiant и Dire.

В полном наборе 1 628 557 пустых ячеек. `isRadiant_avg_r` и `isRadiant_avg_d` целиком пустые. В классификации и PCA они исключены, оставшиеся 312 столбцов используются как признаки. Медианы для заполнения считаются по обучающим данным.

Каждая работа выбирает `6000` исходных строк через `sample(n=N_MATCHES, random_state=42)`. Полный CSV не сокращён и не изменён. Этот размер выбран для времени выполнения SVC и иерархической кластеризации. Чтобы работать с полным набором, можно заменить эту строку на `df = df.sort_values('dt_match').reset_index(drop=True)` в нужном скрипте; время и расход памяти увеличатся.

Если файл потеряется, скачайте его со страницы Kaggle или командой:

```powershell
Invoke-WebRequest 'https://www.kaggle.com/api/v1/datasets/download/teocalvo/dota2-pro-players-matches-2019-202106' -OutFile dotascience.zip
Expand-Archive dotascience.zip -DestinationPath .
```

Исходные CSV исключаются общим `.gitignore` репозитория и остаются локально. Python-скрипты не скачивают данные при каждом запуске.
