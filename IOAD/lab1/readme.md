## Что происходит в коде

- `np.random.randint()` создаёт массив случайных целых чисел. `arr[0, :]` выбирает первую строку, а `arr1[arr1 == 5]` оставляет только пятёрки.
- `pd.Series` — один столбец с индексом. Для него считаются сумма, среднее, стандартное отклонение и уникальные значения.
- `pd.DataFrame` — таблица. В первой части ей задаются названия столбцов, удаляются строка и столбец через `drop()`, затем подсчитываются элементы со значением 50.
- `pd.read_csv()` читает данные клиентов. В исходной таблице 10 000 строк и 11 столбцов.
- В `part2.py` для `Credit_Score` строятся гистограмма и boxplot, выводятся среднее, медиана и `describe()`.
- `groupby(['Employment_Status', 'Default_Risk']).agg(...)` собирает статистику по сочетанию занятости и риска: доход, кредитный рейтинг и задолженность.

## Что надо понимать

Среднее использует все значения и чувствительно к выбросам. Медиана делит отсортированные значения пополам. Стандартное отклонение показывает разброс относительно среднего.

В `describe()` поле `count` — число непустых значений, `std` — стандартное отклонение, `25%`, `50%`, `75%` — квартили. `50%` совпадает с медианой.

На гистограмме видно, какие значения встречаются чаще. В boxplot прямоугольник идёт от первого до третьего квартиля, линия внутри — медиана. За границами усов отображаются возможные выбросы. Для boxplot пропуски убраны через `dropna()`.

Случайные массивы при каждом запуске разные, поэтому конкретное число найденных элементов может меняться.
