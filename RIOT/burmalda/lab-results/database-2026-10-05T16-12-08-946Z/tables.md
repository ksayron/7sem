# ЛР 4 — результаты реальных опытов

PostgreSQL; запросы через gateway. Конкурентные запросы выполнялись двумя отдельными CLI-процессами. Каждый опыт повторён дважды. Время UTC.

| Механизм | Клиент | Отправка (часы клиента) | Вход | Выход | Результат |
|---|---|---|---|---|---|
| Без синхронизации | Client 2 | 16:12:03.084 | 16:12:03.191 | 16:12:03.276 | SUCCESS |
| Без синхронизации | Client 1 | 16:12:03.084 | 16:12:03.191 | 16:12:03.276 | SUCCESS |
| lock | Client 1 | 16:12:03.422 | 16:12:03.515 | 16:12:03.537 | SUCCESS |
| lock | Client 2 | 16:12:03.431 | 16:12:03.538 | 16:12:03.540 | FAIL |

Вход/выход без lock: интервал check → save. Для lock: временные метки внутри критической секции непосредственно перед работой и освобождением.

| Опыт | Общая транзакция | Операция 1 | Операция 2 | Ошибка | Состояние БД |
|---|---|---|---|---|---|
| 1 | Нет | Выполнена | Выполнена | Нет | Saved; выдач 1; экземпляр занят |
| 2 | Нет | Выполнена | Не выполнена | После операции 1 | Partial; выдач 1; экземпляр свободен |
| 3 | Да | Выполнена | Выполнена | Нет | Committed; выдач 1; экземпляр занят |
| 4 | Да | Выполнена | Не выполнена | После операции 1 | RolledBack; выдач 0; экземпляр свободен |
| 5 | Да | Выполнена | Выполнена | Перед COMMIT | RolledBack; выдач 0; экземпляр свободен |

После ROLLBACK выполненные внутри транзакции операции отменены. Partial: выдача сохранена, экземпляр свободен — состояние некорректно.

| Критерий | Без общей транзакции | С транзакцией |
|---|---|---|
| Связанные операции | Два отдельных сохранения | В одном BEGIN |
| Атомарность | Нет | Да |
| Частичное изменение | Возможно | Исключено при успешном ROLLBACK |
| COMMIT | Отдельные autocommit | Явный общий COMMIT |
| ROLLBACK | Нет общей отмены | Явный общий ROLLBACK |
| Сохранение при успехе | Обе операции сохраняются | Обе операции сохраняются |
| Отмена при ошибке | Первая операция остаётся | Изменения отменены |
| Согласованность | Может нарушаться | Сохранена |

| Часть | Условие | Ожидание | Получено |
|---|---|---|---|
| Конкурентный доступ | 2 клиента, Resource = 1, lock | Один SUCCESS, один FAIL | Один SUCCESS, один FAIL |
| lock | 2 клиента | 1 выдача | 1 выдача |
| Транзакция | Без ошибки | COMMIT | Committed |
| Транзакция | Ошибка после операции 1 | ROLLBACK | RolledBack |
| БД | После COMMIT | Изменения сохранены | 1 выдача, экземпляр занят |
| БД | После ROLLBACK | Изменения отменены | 0 выдач, экземпляр свободен |

Сага — учебная модель на отдельной БД, без транспорта RabbitMQ. Успех: 1 выдача, 10 BD в резерве, книга занята. Ошибки Economy/Lending: обратные действия завершены, 0 выдач, 0 BD, книга свободна.
